# Property Analytics quick use

The original file uploader is still for county/STR data.

Use the new **Property File** uploader for owner/property CSVs.

For OH / MO / PA, upload each state's file separately. The program merges the states into the same project. If you upload Ohio again later, it replaces Ohio's Property Analytics while Missouri and Pennsylvania remain.

### Heatmap
Use the existing `Color By` dropdown. Property options are below the STR options.

For property metrics:
- Automatic ranges use data-driven quintile breakpoints for the currently visible counties.
- Custom ranges lets you enter four thresholds.

### Points
Enable `Property Points`, choose one state in the State filter, and zoom to 7 or closer. The app retrieves only points inside the current map window.
