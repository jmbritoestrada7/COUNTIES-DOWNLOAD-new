# V8.2 — Property Point Controls

Built on V8.1 REF UPSERT.

New controls for uploaded property points:
- Show / hide property points.
- Point size slider (1–15 px).
- Point fill color picker.
- Point opacity slider (10–100%).
- Point outline color picker.
- Live preview and Reset button.
- Settings are saved in the project and synchronized across users.

Existing REF upsert, county metrics, STR, property analytics, drawings, and R2 persistence remain intact.
